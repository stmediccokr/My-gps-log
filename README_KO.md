# 나의 GPS 기록장 PWA

## 포함 기능
- 홈 화면 설치용 Web App Manifest와 아이콘
- Service Worker 캐시를 통한 앱 화면 오프라인 재실행
- 브라우저 로컬 저장소 기록 및 CSV 내보내기
- 약 1분마다 위치 측정 요청

## 배포 방법 (필수: HTTPS)
1. `MyGpsLogPWA.zip` 압축을 풉니다.
2. `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` 폴더를 HTTPS를 지원하는 정적 웹 호스팅에 업로드합니다.
3. 업로드된 HTTPS 주소를 Android Chrome에서 엽니다.
4. 위치 권한을 허용하고 메뉴(⋮)에서 '앱 설치' 또는 '홈 화면에 추가'를 누릅니다.
5. 처음 앱을 한 번 온라인으로 열어 캐시가 만들어지면 앱 화면은 오프라인에서도 다시 열 수 있습니다.
6. 기록을 CSV로 내보내 주기적으로 백업합니다.

## 한계
- GPS 웹 권한은 HTTPS 또는 localhost에서만 보장됩니다. `file://`에서 직접 열면 위치 기능이 제한될 수 있습니다.
- 오프라인 캐시는 앱 화면과 파일을 위한 것이며, GPS 측정은 기기의 위치 서비스/브라우저 지원에 의존합니다.
- 브라우저가 백그라운드에서 정지되거나 화면이 꺼지면 1분마다 기록하는 것을 보장하지 않습니다. PWA는 네이티브 앱의 지속적인 백그라운드 위치 수집을 대체하지 않습니다.
- 기록은 해당 브라우저의 localStorage에 저장됩니다. 사이트 데이터 삭제 또는 브라우저 변경 시 사라질 수 있으므로 CSV 백업이 필요합니다.
- 위치 데이터는 서버로 전송하지 않습니다.
